# Dog Breed Identification

An end-to-end multi-class dog breed classification project using PyTorch and Transfer Learning.

## Project Structure

- **`breed_classification.ipynb`**: Jupyter notebook covering data preparation, transfer learning with pretrained models (e.g., MobileNetV2), model training, evaluation, and inference for identifying **120 dog breeds** (Kaggle Dog Breed Identification dataset).
- **`my_imgs/`**: Contains custom/sample dog images used to test the trained model and visualize predictions.

## Requirements

Install required packages:
```bash
pip install -r requirements.txt
```

## Usage

Open and run `breed_classification.ipynb` to train the model or test custom images from the `my_imgs/` folder.
